README - Breezy Tic-Tac-Toe
_________________________

How to Play:

To launch the application, double-click "Breezy Tic-Tac-Toe.exe". 

From there, a practice game (that doesn't record game stats) can be played by clicking the bottom left "Practice" button. Otherwise, the player names can be filled out and "Play Game" can be pressed to play a game where the player names and game stats are recorded in the "Game History" screen which can be accessed with the button on the bottom right. 

From there, just play tic-tac-toe according to the prompt at the bottom of the game screen.
