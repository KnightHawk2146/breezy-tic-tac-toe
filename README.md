# breezy-tic-tac-toe
A tic-tac-toe game I created in December of 2023 as my final project for Intro to Programming at Lake Superior College.
_______________________________________________________________________________________________________________________

<strong>Language:</strong> Python

<strong>GUI:</strong> Breezy GUI (https://lambertk.academic.wlu.edu/breezypythongui/)

<strong>Features:</strong> Fully functional tic-tac-toe game board, a restart button that clears the board, and a game history feature that logs the winner, loser, and date/time of each game to a text file for persistent storage.
